Ownership
Ownership is how Rust manages memory without a garbage collector. Every value has exactly one owner. When you assign a heap value to a new variable, ownership moves and the old variable becomes invalid. This prevents two parts of your code from trying to free the same memory.
Quick Reference
ConceptWhat it means
OwnerThe variable that holds a value. Only one owner at a time.
MoveTransferring ownership to a new variable. The old one becomes invalid.
.clone()Deep copy — duplicates heap data so both variables stay valid.
Copy traitStack-only types like i32 and bool copy automatically. No move.
into_bytes()Consumes a String — the original is gone afterward.
as_bytes()Borrows a String — the original stays valid.
