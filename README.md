# Rust Buddy

**Interactive Rust exercises and flashcards for people learning to build on Solana.**

Live at [rustbuddy.vercel.app](https://rustbuddy.vercel.app)

---

## What It Is

Rust Buddy is a free, interactive learning tool for the Rust programming language — built specifically for people working toward Solana development.

Each topic has two learning tools:

- **Exercises** — work through a concept step by step with broken code to fix, a live Rust Playground, and a built-in answer key
- **Flashcards** — drill the key terms and definitions for each topic with a flip-card deck

Every exercise page has 6 exercises. The first 5 focus on pure Rust mechanics. The 6th is a build challenge — apply what you just learned inside a simplified Solana payment contract.

## How It Was Built

Rust Buddy is the first product built on **Buddy Tech** — an agent-orchestrated technical communications studio that transforms source knowledge into educational content and product assets.

The content source is the HerDAO Rust for Solana course. Each session was transcribed and processed through the Buddy Tech pipeline, which used Claude agents to produce lesson pages, vocabulary sets, and exercise files. Those outputs feed into the Rust Buddy game build.

Exercise and flashcard pages are generated by dedicated Claude agents, committed to this repo, and deployed automatically via Vercel.

---

## Tech Stack

- Pure HTML, CSS, JavaScript — no framework
- Rust Playground embedded via iframe for live code execution
- Deployed on Vercel, auto-deploys on push to `main`
- Content generated by Claude agents (Buddy Tech pipeline)
